ASH Command Line Utility
This is the newest in the line of command line utilities for interacting with your Amiga from your PC.  If you are familiar with the SSH utility of LInux/MacOS then this will be similar experience.  This emulates Amiga shell, connecting you from your PC's command line to the Amiga.
ash [options] host command

Usage:
  ash -l                     List available Amiga hosts
  ash <host> <command>       Execute a single command and print output
  ash <host>                 Interactive shell: type commands, Ctrl+D to quit

Options:
  -h, --help        Displays help on commandline options.
  --help-all        Displays help, including generic Qt options.
  -v, --version     Displays version information.
  -l, --list-hosts  List all available Amiga hosts

Arguments:
  host              Amiga hostname or IP address
  command           Command to execute (optional; interactive if omitted)


ACP Command Line Utility
If you are a command line junky, automation enthusiast or simply someone who feels "cooler" typing with the keyboard rather than clicking with the mouse, the new command line tool should be right up your ally.  This tool works similar to the Linux/Unix command "scp" and allows you to copy files or entire directories to and from your Amiga.  This is super useful if you want to script backups or want to include this as part of your software build process.  This is currently only supported on Linux and Mac because I failed to compile the Qt framework for static linking on Windows.  In the next release this should be hopefully resolved.

Usage: acp [options] source destination
acp file transfer utility

Options:
  -h, --help            Displays help on commandline options.
  --help-all            Displays help including Qt specific options.
  -v, --version         Displays version information.
  -l, --list-hosts      List all hosts
  -d, --list-directory  List all contents in a given path
  -r, --recursive       Copy recursively

Arguments:
  source                From where to copy
  destination           To where to copy

Know Bugs
